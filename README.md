# Country Clustering

## Описание проекта

Данный проект представляет собой систему кластеризации стран с использованием методов машинного обучения.

Модель анализирует социально-экономические показатели стран и распределяет их по кластерам. Проект включает обучение модели, предсказание кластера для новых данных через CLI и веб-интерфейс на Streamlit для визуализации результатов.

## Цель проекта

Цель проекта — разработать простую и наглядную систему для анализа стран на основе ключевых показателей, таких как уровень дохода, инфляция, продолжительность жизни, экспорт, импорт и другие характеристики.

## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/nurse1t08/country-clustering.git
cd country-clustering
```

### 2. Создать виртуальное окружение

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Обучить модель

```bash
python3 train.py
```

После выполнения будут созданы:

- `models/`
- `clustered_countries.csv`

### 5. Запустить CLI-предсказание

```bash
python3 test.py
```

### 6. Запустить веб-приложение

```bash
streamlit run web_app.py
```

### 7. Открыть в браузере

```bash
http://localhost:8501
```

## Использование

Проект поддерживает 3 основных сценария:

- обучение модели кластеризации на основе датасета
- предсказание кластера для новой страны через терминал
- визуализация данных и предсказание через веб-интерфейс

## Как работает модель

В проекте используется:

- `StandardScaler` для масштабирования признаков
- `KMeans` для кластеризации стран
- `PCA` для снижения размерности и визуализации кластеров

## Визуализации

В веб-приложении доступны:

- тепловая карта корреляций
- визуализация кластеров на основе PCA
- распределение признаков
